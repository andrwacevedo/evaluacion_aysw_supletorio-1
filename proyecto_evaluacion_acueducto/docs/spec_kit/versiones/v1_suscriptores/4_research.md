## Criterio de cierre

- [ ] Cada decisión tiene **al menos una** alternativa descartada
- [ ] Cada decisión declara **qué se sacrificó**
- [ ] Los identificadores **no se reutilizan**, ni aunque una decisión se derogue
- [ ] Una decisión derogada **no se borra**: se marca «derogada por `D-vN-n`»

## Errores típicos

| Error | Por qué se paga |
|---|---|
| **Justificar con un argumento falso** | Se cae el día que alguien mida — y arrastra una decisión que era buena |
| **Renumerar al reorganizar versiones** | Una referencia rota se ve; **una reasignada no** |
| Decisión sin alternativa | No se puede discutir |
| Decisión sin costo | Nadie sabe qué se está pagando |
